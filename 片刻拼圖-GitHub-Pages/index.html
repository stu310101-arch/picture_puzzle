片刻 · Small pieces. Good moments.MADE FOR A LITTLE PAUSE ✳

留一點時間，慢慢拼。

  1. 上傳照片，選擇 12、24、48 或 96 片。先看預覽，按「開始拼圖」才會打亂。
  2. 把四周的碎片拖曳到中央。也可以點選碎片，再點目標格子；手機同樣適用。
  3. 位置錯誤會出現紅色提醒；正確時會吸附固定，不能再移動。
  4. 按「結束並檢查」確認進度。全部拼好會有掌聲與彩帶！
  5. 「放棄挑戰」經確認後會顯示完整照片；儲存後可以分享或壓縮連結。

鍵盤也能玩：Tab 選碎片，Enter 拿起，用方向鍵選擇格子，再按 Enter 放下；Escape 取消選取。
